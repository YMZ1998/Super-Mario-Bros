# Super-Mario-Bros
Remake of the original Super Mario Bros game.

Here are the videos explaining how I did it:

Part 1: https://youtu.be/7D4uoSoQsjw

Part 2: https://youtu.be/6SnGgsgV_GY

## To run the game:
1. Install CMake, a C++20 compiler, and SFML 2.5 or newer.
1. Configure the project with `cmake -S . -B build`.
1. Build it with `cmake --build build --config Release`.
1. Run the generated `mario` executable from the build directory.
